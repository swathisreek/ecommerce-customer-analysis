# E-commerce Customer Analysis

## Project Overview

This project analyzes e-commerce customer data using Python and popular data analysis and visualization libraries. The project focuses on understanding customer characteristics, purchasing behavior, ratings, and relationships between different variables.

The project is organized and maintained using Git and GitHub to demonstrate version control and proper project management practices.

## Objectives

* Load and explore the e-commerce customer dataset.
* Understand the structure and characteristics of the data.
* Check for missing values and duplicate records.
* Generate statistical summaries of numerical features.
* Analyze categorical customer information.
* Study relationships between numerical variables.
* Calculate correlations between relevant features.
* Create meaningful data visualizations.
* Organize the project using Git and GitHub.
* Maintain different versions of the project using commits and branches.

## Dataset Description

The dataset contains information about e-commerce customers and their purchases.

### Main Features

* **Age** – Age of the customer.
* **Gender** – Gender of the customer.
* **Product Category** – Category of the purchased product.
* **Purchase Amount** – Amount spent by the customer.
* **Customer Rating** – Rating given by the customer.

The dataset is stored in CSV format inside the `data` folder.

## Analysis Performed

The following analysis is performed in this project:

1. Dataset loading and inspection.
2. Identification of rows and columns.
3. Data type checking.
4. Missing-value analysis.
5. Duplicate-value checking.
6. Statistical summary of numerical features.
7. Analysis of customer age groups.

9. Analysis of purchase amounts.

11. Correlation analysis between numerical variables.
