# E-commerce Customer Analysis

## Project Overview

This project analyzes e-commerce customer data using Python, Pandas, Matplotlib, and Seaborn.

The goal is to explore customer information, understand numerical and categorical features, identify relationships between variables, and create meaningful visualizations.

## Objectives

- Load and explore the e-commerce customer dataset
- Understand the structure and characteristics of the data
- Check for missing values
- Generate statistical summaries
- Analyze categorical customer information
- Calculate correlations between numerical variables
- Create visualizations to understand customer data
- Organize the project using Git and GitHub

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
- Git
- GitHub
